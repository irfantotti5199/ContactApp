# ContactApp

A simple iOS Contact Management application built using Swift and UIKit.

## Features
- View contact details
- Add new contacts
- Edit existing contacts
- Delete contacts
- Clean and user-friendly interface

## Tech Stack
- **Language:** Swift
- **Framework:** UIKit
- **Architecture:** MVC
- **IDE:** Xcode

## Requirements
- Xcode
- iOS Simulator or a physical iPhone
- Swift

## Installation

1. Clone the repository:

   ```bash
   git clone git@github.com:irfantotti5199/ContactApp.git
   ```

2. Open the project in Xcode.
3. Build and run the application.
